Elevor360D Marbella Holiday Companion V1

CUSTOMER APP: Upload index.html, guide.json, manifest.webmanifest, sw.js, both icon PNG files, elevor360d-logo.png and adverts folder to your NEW Marbella GitHub Pages repository.

MANAGER: Use your existing Universal Holiday Guide Manager; import Marbella guide.json, edit and export, then replace only Marbella guide.json on GitHub.

CLICKABLE ADVERT: Upload an image to adverts/advert.jpg, enable the advert in the manager, set the image path and an https:// website link, export guide.json and upload it.

Personal notes and photos remain on the customer device. Back up regularly. External links require internet.
